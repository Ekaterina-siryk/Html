# Popover Widget (Pure JS)

![Build and Deploy to GitHub Pages](https://github.com)

Виджет поповера на чистом JavaScript без внешних библиотек и jQuery.

## Задание
**Popovers**

Есть замечательный фреймворк Bootstrap, в котором реализовано достаточно много интересных виджетов с использованием jQuery. Но, как говорят современные и модные программисты, "jQuery не нужен", поэтому вам нужно реализовать такой же виджет на чистом JS.

### Описание
Виджет всегда должен показываться сверху. У popover'а обязательно должно быть название и текст. Центрироваться он обязательно должен по горизонтали относительно элемента, который вызвал popover. Позиционирование реализовано в пикселях (`px`) без использования `translate`.

##  Особенности реализации
* Использован чистый JavaScript (класс `PopoverWidget`) с модульной структурой и сборкой через **Webpack 5**.
* Позиционирование поповера рассчитывается строго в пикселях (`px`) динамически относительно вызывающего элемента.
* Поповер центрируется по горизонтали и всегда отображается сверху.
* Настроена автоматическая публикация на GitHub Pages через **GitHub Actions** при каждом пуше.
* Написаны автоматические DOM-тесты на базе **Jest** и **JSDOM**.

##  Команды проекта
* `npm install` — установка зависимостей
* `npm start` — локальный запуск проекта (в памяти)
* `npm test` — запуск авто-тестов
* `npm run build` — продакшн сборка проекта
